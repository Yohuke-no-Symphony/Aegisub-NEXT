# 工作台

[English](../en/workbench.md) · [简体中文](workbench.md) · [全部指南](README.md)

## 面板与布局

工作台包含十一个面板：视频预览、时间线、字幕、样式、特效、字幕详细编辑、蒙版、压制、日志、项目素材和绘图工具。拖动标题可停靠、分割、合并标签或浮动。**视图**重新打开隐藏面板，包括**项目素材**和**绘图工具**；**布局**切换标准、打轴、特效、压制或个人预设。当前布局自动保存，命名预设只在显式保存时更新。

## 轨道与导航

- 点击轨道标题或空白区，选择新建字幕和打轴的目标轨道。右键菜单可创建、重命名、排序和删除空轨道。
- 拖动 Clip 移动，拖动边缘裁剪，Ctrl + 边缘拖动拉伸内容时间。同轨重叠会拒绝修改。
- **吸附**对齐其他 Clip 边界；**步进**对齐标尺分度。Alt 暂时绕过两者。未启用步进时按毫秒精度拖动。
- 滚轮上下滚动轨道，Shift + 滚轮横移，Cmd/Ctrl + 滚轮围绕指针缩放；触控板支持捏合和横向滚动。概览条只改变视口，不改变播放位置。
- 时间线获得焦点时，**Cmd/Ctrl + C/V** 复制 Clip 并粘贴到指针位置。多轨复制以复制时选中的轨道为基准保留间距；目标轨道不足或碰撞会拒绝整次粘贴。
- 展开轨道可显示各 Clip 的特效块；展开特效块后编辑关键帧与曲线，特效块默认收起。轨道整体折叠与各特效块展开状态均随工程保存，包含自动保存，不进入内容撤销。左侧工具栏可展开／折叠全部轨道，并保留各特效块状态。
- 字幕轨道头部的 **S** 按钮只在时间线中显示该轨道；关闭按钮或在字幕列表中选择另一轨道即可恢复显示全部轨道。

字幕列表选中项会居中显示主 Clip，缩放保持不变。Enter 提交文字并进入下一行；最后一行可按该行结束时间到播放头创建下一句。Shift + Enter 换行。无效输入和 IME 候选确认保留编辑焦点。

## 播放与打轴

文本输入框外按 Space 播放/暂停。F8 创建新的打轴片段，F9 结束仍有效的片段；定位、切换选择或其他编辑可能使它失效。

旧版 Aegisub 兼容试听键作用于主选字幕：**Q** 试听开始前的短片段，**W** 试听结束后的短片段，**E** 试听字幕开头的短片段，**R** 试听整句。时间线或字幕行需获得焦点，文本输入框内保留正常输入。短片段默认 500 ms，可在**设置 → 预览**中修改；试听范围不会超出媒体边界，E 也不会超出字幕结束时间。

鼠标兼容打轴默认关闭。先选择字幕，再开启时间线左下角鼠标图标对应的**经典 Aegisub 打轴**：在时间线主体**左键点击**设置主选字幕的开始，**右键点击**设置结束，时间取自点击位置。点击不会切换主选字幕；轨道标题和顶部标尺保留原有操作。关闭开关后，主体恢复普通选择、拖动和右键菜单。操作对照见[快速开始](quick-start.md#旧版-aegisub-兼容操作)。

经典鼠标打轴开启时，右键特效关键帧或曲线仍打开对应的特效菜单。

预览画质为低 320p、流畅 540p（默认）、标准 720p、高清 1080p。拖动定位时临时限制到 540p 且不超过所选画质，释放后恢复；小视频不放大，导出不受影响。

设置 → 媒体提供自动/CPU/GPU 预览解码，并按输出设备保存额外音频延迟。正值表示声音更晚到达；设备时钟丢失时暂时禁用打轴，恢复后重新可用。

## 样式、动画与蒙版

样式面板及其浮动子窗口编辑字体、字号、行高、填充、描边、阴影颜色／偏移／模糊和对齐，文字随内容自然伸展。位置由归一化 Anchor/Pivot 和像素 Offset 组成；点击预设保留位置，Shift 同时修改 Pivot，Alt 同时清零 Offset。**恢复自动位置**清除手动位置及位置/路径动画，保留其他效果。

蒙版面板和特效面板的**蒙版定位**共用锚点预设、定位图示及 Anchor／Pivot／Offset 输入。Anchor 相对工程画布，Pivot 相对创建时捕获的蒙版局部参考框；0 表示左／上边，1 表示右／下边，轴心也可位于框外。节点编辑和形变动画不会重算参考框。普通预设保位，Shift 同时设置轴心，Alt 清零像素偏移；直接修改轴心会补偿 Offset，保持当前编辑帧的画面，其他旋转或缩放姿态的画面可能变化。静态定位与**蒙版位移**动画分开，修改定位保留已有动画轨道。两个面板共享未完成输入，Esc 只恢复当前字段。

从轨道右键菜单指定样式预设。有字幕时可选择更新已有 Clip，或仅更新新 Clip 的默认样式。工程保存独立样式快照，个人库后续修改不会改写工程。通过**编辑 → 效果库 → 样式库**管理可复用素材；未嵌入样式的系统字体仍需在目标电脑安装。

**效果库 → 样式库**支持编辑预览文字；Cmd/Ctrl＋滚轮围绕指针缩放，左键拖动平移，仅改变预览的查看方式。样式、脚本、压制和布局库支持多选个人预设，并在删除前二次确认。

选择 Clip 编辑特效，选择关键帧会定位到对应时间并编辑值/插值。可在预览中拖动字幕、运动路径节点或蒙版控制柄。运动路径曲线与控制柄也会显示在预览留白中，并支持拖动。路径和矢量蒙版编辑时，Shift + 左键点击曲线插入节点，Ctrl + 左键点击节点删除；运动路径至少保留两个端点。插入节点保持曲线形状，运动路径播放继续使用现有的按段进度规则。蒙版节点形变动画存在时锁定拓扑，清除这些轨道后解除。详见[字幕编辑](subtitle-editing.md)和[特效脚本](effect-dsl.md)。

Clip 右键菜单可清除所选 Clip 的全部动画轨道。右键特效块、关键帧或曲线，可清除该块的动画，包括关键帧与有序变换；关键帧菜单也可单独删除该关键帧。清除操作保留静态样式、基础位置、蒙版、运动路径和逐字高亮，并形成一条撤销记录。

有效数值/颜色草稿即时预览，Enter 或失焦提交；无效原文保持可编辑，Esc 恢复当前字段。一次完成的手势或提交形成一条撤销记录。

数值输入框保留文本编辑并统一隐藏上下箭头。按住数值字段标题左右拖动可调节草稿，向量通过 X／Y 标题分别调整；松开提交一次。Esc、失去鼠标捕获或切换编辑目标会取消手势并恢复原文，无效文本不启动拖动。可折叠属性分类统一使用通用紧凑控件 `PropertySection`，标题弱化底色并使用与快捷键设置一致的分隔线。

特效面板采用可折叠的属性表，按片段、变换、文字排版、填充、描边、阴影、合成、路径和动画分类，保持工作台主题和输入控件。预设入口固定在底部。属性行显示当前值、动画开关、添加关键帧和恢复操作；详细关键帧编辑仍在面板内，时间与曲线共用主时间轴。

在字幕详细编辑中选择完整文字，再到特效面板创建动画范围。面板顶部可以切换整句／文字范围，以及普通／激活／未激活外观；范围可删除和调整覆盖次序。激活与未激活外观只编辑绘制属性，字号、字距和局部变换使用共用的普通状态几何。动画开关关闭时只清除当前完整目标，不影响其他范围或状态。范围身份会随文字编辑、拆句和复制更新。

普通文字范围的“位置”编辑局部像素偏移，缩放与旋转同样作用于组的已排版几何，保留排版占位；整句“位置”仍移动图层。通过原有预设入口应用**逐字弹跳**或**逐字放大往返**，可生成可编辑的字素范围。版本 2 脚本也支持两字一组、单词、硬行、段落和字面分隔符分组。重新应用同一命名生成块会重置其范围、轨道的手工修改；修改文字只重新映射已有结果，重新应用才重建分组与错峰。完整规则见[特效脚本](effect-dsl.md#版本-2按组执行文字特效)。

分类折叠属于个人设置，不产生工程撤销。折叠、换主题或语言不会提交草稿，无效输入保持原文；错误所在分类会重新展开。范围、状态与属性切换先处理当前草稿，延迟提交只作用于创建草稿时的完整目标。

### 三维旋转与透视

字幕、图片和图形都可以作为平面进行三维旋转。在**特效 → 变换**中，旋转 Vector3 以角度显示 **X、Y、Z**。与位置 Vector2 一样，三轴共用一条轨道和关键帧时间，各分量数值与插值曲线可以分别编辑。**透视距离**以工程像素计，默认 312.5；正值越小，透视越强，不改变工程的输出分辨率。角度保留完整圈数，从 0° 到 720° 的动画会旋转两圈。

选择关键帧后，在曲线分量选择器中选择全部或 X／Y／Z，再设置插值类型和幂指数。Vector2 同样提供全部或 X／Y，颜色提供 R／G／B／A；改变单个分量的曲线不会改变其他分量。紧凑数字输入会裁切过长的小数显示，完整原始值仍用于编辑和保存。

1. 选择 Clip。要编辑一组文字，先在特效面板选择对应动画范围。
2. 在**绘图工具**选择**三维变换**。上下拖动红色 **X** 控制柄，左右拖动绿色 **Y** 控制柄，绕轴心拖动蓝色 **Z** 控制柄。按住 Shift 将旋转吸附到 15°。
3. 左右拖动金色 **D** 控制柄调节透视距离；向右增大距离，向左增强透视。
4. 松开提交一条撤销记录。Esc、失去鼠标捕获或切换目标取消暂存修改。在特效面板启用对应属性的动画，或选择关键帧后，可通过同一组控制柄编辑其值。

即使当前选择激活／未激活外观，三维工具仍编辑所选范围的普通状态几何；选择／移动工具始终编辑整层。导入 ASS 的有序旋转变换可在特效面板按操作编辑，清除旋转轨道后可使用直接控制柄。透视距离和其他范围各自拥有轨道。

Anchor 决定画布位置，Pivot 决定局部旋转中心。修改 Pivot 会通过原生补偿保持当前编辑帧的投影画面，并保留原有轨道；其他帧使用不同旋转或缩放时，画面可能变化。ASS 的 `\org` 只在导入／导出时转换为本项目的锚点／轴心模型，不作为独立的绝对原点设置。可调透视、轴心补偿和范围叠加请保存为 `.aeginext`；ASS 交换会提示无法表达的组合。

## 分享样式与脚本

打开**编辑 → 效果库**，选择**样式库**、**特效脚本**或**导入与导出**。欢迎页也可在没有工程时打开同一个三页效果库。切页和关闭时会处理未保存的素材草稿；工作台原有应用／捕获入口继续可用。

**特效脚本**页预览当前草稿，支持文字、时长、个人样式及嵌入字体，提供播放／暂停、循环和拖动定位。无需保存或打开工程即可查看效果；详见[草稿预览](effect-dsl.md#草稿预览)。

在效果库任一页面点击**导出…**，打开**导出效果库**窗口。每次打开时，树中列出已保存的个人样式和脚本，初始没有勾选。导出保留当前编辑页及未保存草稿；若要分享草稿版本，请先保存再打开导出窗口。

勾选要分享的素材，也可按名称或脚本标识搜索。树节点的名称与数量或脚本标识在同一行显示。样式和特效树根的复选框只操作当前匹配的可见条目；被搜索隐藏的勾选仍会保留。工具栏的**全选**和**全不选**作用于整个个人库，包括被隐藏的条目。搜索框内的 × 只清空搜索词，不改变勾选。

默认格式为**效果库包（.aegilibrary）**，也可选择**独立文件**：样式使用 `.aegistyles`，个人脚本使用 `.aegieffect`。所有勾选项都是脚本时，还可选择**脚本原文（.aegifx）**。点击**导出所选素材**：打包格式选择包文件；独立文件与脚本原文单项选择文件，多项选择输出目录。导出整个个人库时，先使用工具栏**全选**，再以所选格式**导出所选素材**。

在**特效脚本**页也可选中一个或多个脚本，通过**导出原文…**直接分享 `.aegifx` 原文；该入口导出已保存的个人脚本和只读内置脚本，不包含未保存修改。取消输出位置选择会保留导出窗口的搜索、勾选和格式；导出失败在该窗口显示，可重试。关闭窗口会取消未完成的操作并等待清理结束。

**导入**可混选多个独立文件和包。检查新增、相同和冲突行，按可用选项选择**导入**、**替换**或**跳过**，再确认；相同内容自动跳过。受保护的身份不能替换，同组冲突输入最多选择一个版本。库发生变化后需要重新预览、再次确认。设置包在设置中单独导入，不用于提取效果库素材。

## 保存与恢复

设置 → 工程指定工作区根目录，初始为 `Documents/AegiNext/Workspace`。创建 `Example` 会生成 `Example/Example.aeginext` 和 `Example/backup/`；目标目录已存在时拒绝创建。

自动保存与备份默认分别开启：每 2 分钟自动保存，每 5 分钟备份，保留 20 份。两者只保存已提交状态，不提交草稿、不改变 Undo。标题圆点表示尚未保存。

恢复时先关闭工程，将 `backup/Example-yyyyMMdd-HHmmssfff.aeginext` 拷回工程根目录，再打开该副本。保留工程媒体和托管资源；备份不会复制它们。

工程目录内的视频使用相对引用，外部视频使用绝对路径，视频不会复制。另存为重新分类引用并迁移托管资源；整体移动目录可保留相对引用。格式兼容见[架构](architecture.md)。

## 设置与日志

设置管理语言、主题、主色/音频/时间线颜色、快捷键、媒体、工程、预览和打轴选项。快捷键录制捕获实际按键组合，Esc 取消，清除可禁用；macOS 可选择系统或窗口菜单。

日志支持筛选、复制和清空，最多保留 2,000 条本次会话记录。错误在视图菜单提示且不抢焦点，重启后不保留。
