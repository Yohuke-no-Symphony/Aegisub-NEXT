# 快速开始

[English](../en/quick-start.md) · [简体中文](quick-start.md) · [全部指南](README.md)

## 打开工程

1. macOS 打开 `AegiNext.app`，Windows 打开 `AegiNext/aegi-next.exe`。保留完整应用包。
2. 在欢迎窗口选择**新建工程**，填写名称和父目录并创建。目标目录不能已存在。
3. 选择**文件 → 打开视频**，等待画面出现；音频分析在后台进行。

已有 `.aeginext` 文件使用**打开工程**。源码运行见[构建](building.md)，最低系统要求见应用包的 manifest。

## 制作字幕

1. 点击时间线轨道标题，选择目标轨道。
2. 按 **Space** 播放，在句子开始时按 **F8**，结束时按 **F9**。
3. 在**字幕**面板输入文字。起止时间支持秒数或 `00:00:12.350`。
4. 拖动 Clip 移动字幕，拖动边缘裁剪。同一轨道的字幕不能重叠。

手动创建时，定位到开始位置并按 **Cmd/Ctrl + Enter**。已有字幕使用**格式 → Aegisub** 或**格式 → SRT** 导入；重叠字幕会分配到独立轨道。

## 调整与检查

- **样式**：设置字体、字号、填充、描边、对齐和位置；可在预览中拖动文字。
- **特效**：选择并应用预设，展开轨道三角按钮编辑关键帧。
- **字幕详细编辑**：编辑富文本、卡拉 OK，并试听选中片段。
- **蒙版**：为当前字幕创建矩形或闭合贝塞尔蒙版。

在**视图**菜单重新打开隐藏面板，使用**布局 → 标准**恢复初始布局。预览画质只影响编辑，默认流畅 540p。

## 保存与导出

1. 按 **Cmd/Ctrl + S** 保存工程。视频仍以外部引用保存。
2. 打开**压制**面板，选择**烧录字幕**并设置编码与音频，或选择**内挂字幕（仅封装）**添加播放器可开关的字幕轨。点击**压制**或**导出**，选择尚不存在的输出文件。
3. 完成后检查视频、字幕和音频；**取消**可停止任务。

字幕文件使用**格式 → Aegisub/SRT → 导出**。内挂字幕默认 MKV，复制原音视频且只保留新字幕的文字与时间。容器选择、转换限制、HDR 与 GPU 选项见[视频导出](export.md)，自动保存和备份恢复见[工作台](workbench.md)。

## 常用快捷键

macOS 使用 Cmd，Windows 使用 Ctrl；实际绑定以**设置 → 快捷键**为准。

| 操作 | 默认快捷键 |
|---|---|
| 新建 / 打开工程 | Cmd/Ctrl + N / O |
| 打开视频 | Cmd/Ctrl + Shift + O |
| 保存 / 另存为 | Cmd/Ctrl + S / Shift + S |
| 播放 / 暂停 | Space |
| 打轴开始 / 结束 | F8 / F9 |
| 添加字幕 | Cmd/Ctrl + Enter |
| 撤销 / 重做 | Cmd/Ctrl + Z / Shift + Z |
| 导出视频 | Cmd/Ctrl + E |

文本输入框保留本地输入行为。功能键被系统占用时，可使用字幕菜单或修改绑定。

### 旧版 Aegisub 兼容操作

先选择字幕，再使用以下操作。Q/W/E/R 在时间线或字幕行获得焦点、且未编辑文本时生效；短片段默认 500 ms，可在**设置 → 预览**调整时长。

| 操作 | 默认按键 / 鼠标 |
|---|---|
| 试听字幕开始前的短片段 | Q |
| 试听字幕结束后的短片段 | W |
| 试听字幕开头的短片段 | E |
| 试听整句字幕 | R |
| 在点击位置设置主选字幕的开始时间 | 时间线主体左键 |
| 在点击位置设置主选字幕的结束时间 | 时间线主体右键 |

鼠标打轴需开启时间线左下角的**经典 Aegisub 打轴**（鼠标图标，默认关闭）。开启后，主体区域的左、右键始终修改当前主选字幕，不切换选择；关闭后恢复普通选择、拖动和右键菜单。
