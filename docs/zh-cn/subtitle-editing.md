# 字幕编辑

[English](../en/subtitle-editing.md) · [简体中文](subtitle-editing.md) · [全部指南](README.md)

## 轨道与叠覆

同一轨道可以包含字幕、图片和形状。轨道内片段不能重叠；需要叠覆的片段放到不同轨道。越靠上的轨道越显示在前，预览和导出一致。

拖动轨道头即可重排序，所属片段和动画行一起移动，插入线提示目标位置。释放后提交一次可撤销编辑，顺序随工程保存；Esc 取消拖拽。Solo 和折叠按钮仍执行各自操作。

## 时间线 Clip 定时

字幕 Clip 默认以 1 ms 增量移动、调整左右边界，裁剪后至少保留 1 ms 时长。启用 **Step** 时对齐当前标尺刻度；启用吸附时，Clip 的任一边缘可吸附其他 Clip 边界或当前播放红线，保留目标的精确时间。按住 Alt 临时绕过 Step 和吸附。

向左延长 Clip 会保留已有特效关键帧的工程时间位置；可在扩展后的整个 Clip 内移动或新增关键帧。每次拖动完成只提交一次，可通过 Undo 撤销。

选中 Clip 后，按 **Shift+Q** 定位到开始，按 **Shift+W** 定位到结束；多选时使用主选中 Clip。定位保持当前播放状态与缩放，并将视野外的目标带回时间轴可视区域。文本输入框保留大写 Q/W 的输入；可在**设置 → 快捷键 → 播放与试听**中修改或禁用。

在字幕列表或时间线中多选，右键选择**移动**，输入整数毫秒后点击**确定**。正值向后，负值向前；所有目标的起止时间按同一偏移调整，保留时长、相对间隔和内部动画时间。字幕列表移动已选字幕，时间线移动整个已选 clip 集合。取消或输入 0 不移动；任一目标越过零秒，或移动后片段在同轨发生重叠，整批拒绝。一次 Undo 撤销整批移动。

## 富文本与卡拉 OK

选择字幕，通过视图菜单或字幕行打开**字幕详细编辑**。面板可停靠或浮动，在同一原生界面编辑正文、文字范围外观和计时；ASS 标签只用于导入、导出。顶部方形外观按钮展开三种编辑状态：右下角的灰色圆环、琥珀色时钟和绿色勾选分别表示普通、未激活和已激活外观；悬停显示当前状态。播放、循环、吸附、时长显示和链条图标的计时联动按钮与计时编辑按钮位于计时轴上方同一行；回转箭头的**重置**位于末尾，并由分隔线隔开。

1. **普通**状态编辑选中文字的字体、字号、强调、填充、描边和阴影。**未激活（INACTIVE）**与**已激活（ACTIVE）**状态分别预览和编辑高亮前后的外观；未计时或已停用的文字也可保存这两种范围样式。没有文字选区时，高亮外观作用于整句；ACTIVE 的整句预设可作为默认外观。
2. 选择未计时的完整文字，点击**为选区建立计时**，明确输入开始和结束时间。打开面板和普通文字编辑不会自动计时。首次点击**启用高亮**且没有计时数据时，按完整字素等分本句可见时长；已有完整组保持分组，停用缓存优先恢复。计时工具栏的**重置**会按完整字素重新生成整句计时，替换本句已有的启用与停用组。
3. 一个计时组可以包含多个 Unicode 字素。导入、打开、保存和日常编辑保留完整组；组内每字可独立修改高亮外观，无需拆时间。只有**拆分为逐字**按完整 Unicode 字素精确等分所选组。在轴上用 Ctrl/Meta 点击增减多选，用 Shift 点击按正文顺序选择范围，然后点击**合并所选计时组**。所选组必须文字连续、时间首尾相接且高亮模式相同；空档、重叠或倒序不能合并，禁用提示会说明原因。一次 Undo 撤销整批合并。
4. **计时联动**默认关闭，此时在计时轴拖动左柄、右柄分别修改本组开始和结束，拖动组主体同时平移两端并保留时长。组间可以留空、时间重叠，或按与正文不同的时间顺序播放；拖动不会自动挤走相邻组。显示时间相对字幕的可见起点，可以为负，但内容时间必须非负、每组时长必须为正。
5. 卡拉 OK 按钮条的**计时联动**统一控制数值输入和拖拽。启用时，开始输入或左柄带动正文前组，结束/时长输入或右柄带动后组，拖动主体带动两侧；其他组保留时长和原有间隔。关闭后只编辑当前组。**最早开始**平移全部启用组，以时间最早的一组为准并保留时长、空档和相对顺序。**恢复保存的计时**恢复停用组；关闭卡拉 OK 保留计时缓存和独立外观。

可选时长显示会显示全部组长度，默认仅拖动时显示。密集标签可以覆盖本面板内的元素，但会在面板边界裁剪，不遮挡其他面板或标签栏。时间超出字幕可见范围时显示红色溢出区域，不改变字幕边界。**显示全部计时**调整计时轴视野，不修改项目。

正文和样式的有效草稿在 Enter 或失焦时提交；退出当前输入会提交该字段的有效值，或恢复其无效值，并保留其他字段草稿。组时间弹窗内在开始、结束、时长之间转焦不会提交，便于作为一组校验；Enter、正常关闭弹窗或执行外部命令时才提交有效计时草稿。面板顶部的**重置**丢弃尚未提交的正文、样式和计时草稿，与计时工具栏重新生成计时的**重置**分开。取消手动创建只丢弃创建弹窗输入，取消组时间弹窗只丢弃时间草稿。一个完成的范围手势和已有有效草稿合并为一次 Undo；目标、内容、时间原点或联动模式变化会取消未完成的手势。

文字修改保留未受影响组的身份和时间。组内插入继承整组时间，组边界插入为未计时文字；删除文字留下时间空档，不把时间让给邻字。跨组替换按原文字映射；无法归属已有组的新文字不自动计时。组合字符、emoji 的完整字素不能跨越不同计时归属；若编辑会破坏该边界，操作被拒绝。分句若需要切开组内部，先显式拆组。

工程保存为 v14，可读取 v3–v14。首次读取 v3–v10 项目时在内存中执行旧的逐字等分迁移，保留旧播放行为，并把旧片段的 ACTIVE/INACTIVE 外观转为独立文字范围样式。读取 v11–v14 不再自动等分，也不重复迁移独立范围外观；打开旧文件不回写，用户保存时才写出当前格式。兼容范围见[时间与存储](architecture.md#时间与存储)。

在**样式**面板通过两组图标按钮设置对齐：水平左／中／右、垂直上／中／下。切换一个方向时保留另一个方向，样式库也使用相同控件。组合值对应 ASS 的 `\an1`～`\an9`；显式位置继续由位置编辑器控制。旧工程保留独立文字对齐，直到用户主动选择对齐，此时清除旧覆盖。

样式面板和**效果库 → 样式库**使用相同的四组与顺序：**字体、填充与描边、阴影、布局与位置**，各组始终展开。字体选择右侧同行放置粗体、斜体图标开关，下方字号与行高同行；填充和描边各占一行。布局与位置使用一张图同时展示边距和位置。效果库另保留预设命名、示例预览和工具栏。

**字距**调整塑形后的文字簇间隔，支持负值；组合字符与连字保持完整。**填充模糊**和**描边模糊**分别控制两种边缘，与阴影模糊、整层模糊独立。这三项可在样式面板、局部文字和样式库中编辑，也可创建原生动画或在效果脚本中使用。高亮样式提供两项边缘模糊，字距由正文排版统一控制。动画后的字距同步用于画布边界、文字命中和定位。

**换行方式**作用于整句：**按字素换行**延续现有排版；**自然换行**优先使用 Unicode 断行机会，并保留不换行空格的连接关系；**不自动换行**只在显式换行处分行。已有工程与样式库迁移后继续使用按字素、零字距、零填充/描边模糊，原有外观不变。

在定位行选择**自动排版**或**自定义锚点**。自动排版收起锚点、轴心和偏移输入，保留九宫格与图示；点击九宫格预设会进入自定义模式。切换模式保留图层的位置效果。样式面板的重置图标会恢复自动排版，并通过一次可撤销编辑清除位置偏移、运动路径和位置动画。效果库使用模式选择，不再提供重复的重置操作。

**边距**在样式面板和**效果库 → 样式库**中提供独立的**左、右、垂直**值，单位为画布像素。左、右边距限定自动换行区域，水平居中使用该区域的中心，因此不等边距会移动居中文字。垂直边距控制顶部／底部排版位置，垂直居中时忽略。显式位置接管定位并禁用垂直输入，左、右边距仍限定换行宽度。边距按文字排版计算，描边和阴影可以越过该范围；保留已有垂直基线位置。共用位置图展示排版区域和自动／显式位置。非法输入保留原文并阻止新预览、保存或应用；Esc 只恢复当前字段。

## 片段试听

顶部播放/暂停按钮试听选中 Clip，未选中时试听整句。**循环**重复播放范围，默认关闭；暂停时切换循环不会开始播放。

离开整个面板或浮窗失活会暂停。切换目标、关闭面板或在主窗口定位会取消旧范围；音频和视频同步播放。

## 导入与导出

| 菜单 | 格式 |
|---|---|
| 格式 → Aegisub → 导入 / 导出 | ASS 样式、卡拉 OK 和受支持的蒙版 |
| 格式 → SRT → 导入 / 导出 | 文字与时间 |

导入创建独立轨道，重叠字幕保留原时间并分配到额外轨道，一次 Undo 撤销整批。ASS PlayRes 映射到现有画布；结构、时间、尺寸、UTF-8 或资源限制无效时拒绝导入。

ASS 支持基础/局部样式、重置、颜色/透明度、描边/阴影、对齐/位置、整行静态缩放与 Z 旋转、`\move`、`\fad`/`\fade`、`\k`、`\kf`/`\K`、`\ko`、`\kt`、矩形/矢量裁切及受支持的矩形变换。导入的位置和透明度动画进入原生轨道，可在画布、特效面板和时间轴编辑与撤销。普通淡入淡出使用关键帧；含瞬时跳变的包络使用有序变换，在特效面板的变换操作中编辑。

导出保留可对应的变换参数、匀速直线移动和最多两段渐变的透明度包络；可识别的变速直线和缓动淡化会报告匀速/线性近似。复杂动画不能对应时只省略该部分，不修改工程。透明度包络保留填充、描边、阴影各自的 alpha；项目在整层合成后应用透明度，ASS 在文字内部应用淡化，重叠像素仍可能不同。字体度量、缩放换行及非等比描边也有外观差异，参数对应不代表逐像素一致。

导入解析空参数重置，按 `ScaledBorderAndShadow` 和有效 `LayoutRes` 换算描边、阴影。非等比描边按两轴几何平均值近似，缺少原视频分辨率时会提示。独立计时的正空档输出为空等待 `\k`；负相对起点、重叠或倒序需要 `\kt`，部分工具不支持。多字组不会为了导出范围样式而自动拆组；组内样式段可能在目标播放器形成不同的激活或扫色效果。

转换提示列出字幕序号、时间、文字及具体损失，详细内容可复制。取消导入保留项目，取消导出保留已有目标文件；无需启用兼容模式。

`Spacing`／`\fsp` 对应原生字距，支持局部覆盖；`\blur` 按最终描边宽度选择填充或描边模糊，并换算为原生高斯模糊单位。ASS 同时耦合阴影模糊，独立双模糊与独立阴影不能完整往返，转换提示会指出差异。完整 `LayoutRes` 决定模糊重采样；缺失时按 PlayRes 估算并提示。原生填充、描边和阴影模糊通过各自 UI 编辑，普通文字修改不会丢失它们。

`\q2` 对应不自动换行，`\q1` 对应自然换行；智能均衡的 `\q0/3` 导入自然换行并提示。每处软 `\n` 在当时 q2 状态下变为硬换行，否则变为空格；最终 q 决定整行换行方式。原生按字素换行导出为 q1 并报告可能的断行差异。完整边界见 [ASS 互转换能力](ass-compatibility.md)，逐标签四维审查见 [ASS 标签审查](ass-tag-audit.md)。

受支持的整行或局部 `\t` 可转换字号、字距、颜色与 alpha、阴影偏移、边缘模糊、描边宽度、缩放和 Z 旋转。可直接对应的连续单段进入幂函数关键帧，重叠或瞬时变化进入有序变换；需要逐操作钳制、字号复位或坐标耦合时采样并报告误差边界。普通数值框对有序属性显示求值和编辑提示，其他属性与画布位置移动照常使用。外部 ASS 的负缩放与描边按零处理，shad 插值后钳制非负，blur 插值后限制到 0～100；x/yshad 保留负值。原生负缩放镜像继续保留，出口遇到当前无法表达的分量会提示。自定义轴心、描边/阴影耦合和部分缓动无法完全对应时，具体差异列入转换提示。

ASS 样式的 `MarginL`、`MarginR`、`MarginV` 分别映射三项边距。Dialogue 中非零值只覆盖对应项，零值继承样式。导入时左／右按 PlayRes 宽度比例缩放，垂直按高度比例缩放。导出分别写出三项，普通边距定位保持自动，显式 `\pos` 定位继续保留。导出使用 `WrapStyle: 1`；字体度量与换行仍可能与 ASS 播放器不同。

导出包含所有字幕轨道。SRT 报告富样式、高亮、蒙版和动画的损失；ASS 根据轨道顺序生成层。工程保留精确时间，仅输出时量化为 SRT 毫秒或 ASS 厘秒。卡拉 OK 起止时间独立量化；极短的正时长至少输出 1 厘秒并提示可能的重叠，超出播放器的 32 位毫秒范围时拒绝导出；文件使用 UTF-8 和原子写入。

## 合并多人分段工程

所有成员使用完整原片打轴时，在主工程选择**文件 → 合并其他工程…**，一次选择一个或多个 `.aeginext` 文件。

合并保留来源的原始时间，为每个来源新增“工程名／轨道名”独立轨道，保留轨道顺序和默认样式。字幕、富文本、卡拉 OK、形状、图片、动画、蒙版及工程内效果预设一并导入；来源轨道整体放到主工程上方，后选择的来源显示在前，并保留各来源内部的轨道顺序。

主工程继续使用自己的视频、画布、帧率、参考白和时间轴视图。来源画布尺寸、参考白必须与主工程一致；帧率差异不改变精确字幕时间。此流程适用于时间已对齐的完整原片工程，不自动推断或移动分段时间。

托管字体和图片复制到主工程的 `assets/` 或 `sources/`，相同内容复用资源。外部链接图片保留源文件引用，并按主工程位置重新计算路径；视频不复制。素材库中的图片即使未被 Clip 使用，也会参与合并。交付时应提供来源工程及其托管资源，并保持外部链接图片可访问；系统字体仍需在汇总电脑安装。缺失资源、哈希不一致、损坏工程或超出预算会拒绝整批合并；备份先拷回来源工程根目录再导入。

一次 Undo 撤销本次选择的全部工程，Redo 可恢复；资源文件保留供历史使用。核对完成后保存主工程，重新打开仍可使用合并后的内容。

## 蒙版

在**蒙版**面板创建矩形或闭合多轮廓贝塞尔几何，再在预览中编辑。蒙版以项目的 Anchor／Pivot／Offset 定位到工程画布，仅裁切所属 Clip 的文字、描边、阴影、卡拉 OK 和自身模糊。字幕变换不移动蒙版，蒙版自身变换负责移动；支持反相和非零环绕规则的孔洞。

在蒙版或特效面板的**蒙版定位**区域，通过九宫格、图示和数值调整定位。Pivot 使用创建时的固定局部参考框，编辑节点或播放形变时保持该参照。预设保位，Shift 同时调整轴心，Alt 清零偏移；修改轴心通过 Offset 保持当前帧，已有动画轨道继续保留。**蒙版位移**独立编辑动画，矩形角和节点位置使用蒙版局部坐标，控制柄使用相对节点的像素偏移。ASS 的画面坐标仅在导入和导出时转换。

蒙版几何和动画通过原生蒙版工具编辑。节点形变存在时，修改拓扑前须先清除对应节点轨道。

ASS 将可精确表达的矩形动画输出为 `\t`，其他蒙版动画展开为逐帧静态事件并报告采样与坐标舍入。展开事件按各自实际对白起点计算卡拉 OK 时间，必要时使用 `\kt`；目标播放器须支持它。导出上限为 100,000 条事件。
