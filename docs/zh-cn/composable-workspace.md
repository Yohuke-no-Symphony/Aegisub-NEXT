# 工作区集成

[English](../en/composable-workspace.md) · [简体中文](composable-workspace.md) · [全部指南](README.md)

## 按职责落位

下列目录均在 `src/AegiNext.Desktop/` 中。

| 目录 | 职责 |
|---|---|
| `Workspace/` | 唯一 WorkbenchSession、编辑器/控制器、选择、草稿和可等待工作流 |
| `Layouts/` | Dock 树、浮窗、布局快照和预设 |
| `Panels/` | 功能 View 与 ViewModel |
| `Controls/Common/`、`Controls/Editing/`、`Editing/` | 共享控件及字段/手势编辑行为 |
| `Settings/` | 偏好、压制／颜色标记库及其草稿 |
| `EffectLibrary/` | 样式／脚本草稿、独立窗口与分享流程 |
| `Views/`、`Windowing/` | 宿主、平台外观、菜单和输入协调 |
| `I18n/` | 语言服务、JSON 语言包和实时绑定 |

新增 API 前先阅读使用面板与最近的共享控件。共享控件暴露值、草稿、命令和完成/取消事件，不主动取得会话、不依赖 Dock；ViewModel 保存业务状态而非控件/像素。

## 接入面板或控件

1. 在功能目录新增 View/ViewModel，在 Workspace 组合依赖。
2. 按稳定 `WorkbenchPanelIds` 为布局控制器提供固定 View，停靠/隐藏不重建实例。
3. 实际输入通过共享命令路由，保留文本输入与 IME 行为。
4. 切换编辑目标前提交有效草稿；无效原文保持原目标，Esc 只恢复一个字段。
5. 一次完成的手势提交一个事务；捕获丢失或目标变化时取消。关闭时等待异步工作并释放自有资源。

布局只管理空间，不拥有编辑器、Undo、播放或导出。当前布局和命名预设独立；持久化校验应用自有快照并原子写入，恢复浮窗时限制到可用显示器。关闭浮窗隐藏面板，关闭主窗口刷新布局并等待会话结束。

可折叠属性分类统一使用 `Controls/Common/PropertySection`。`WorkbenchTheme.axaml` 中的类型主题提供 28 DIP 紧凑标题、透明底色、弱化文字和与快捷键设置一致的分隔线。消费者提供 Header、Content 和 IsExpanded；控件不保存折叠偏好，不提交编辑。

数值字段使用无箭头的 `NumericDraftInput`，并为 `NumericDragLabel.Input` 绑定该字段；`VectorDraftInput` 内部提供 X／Y 拖动标题。DragStarted／DragCompleted／DragCanceled 向上冒泡，携带输入身份及原始／最终原文。IsTitleDragging 期间，消费者抑制失焦和即时数值提交；开始时冻结完整业务目标、源快照和时间，完成时提交一次，替换草稿或全局提交前取消尚未完成的手势。个人预设编辑继续使用原来的保存／应用事务边界。无效原文不能启动拖动，取消恢复完全相同的原始文本。

字体字段共用 `FontFamilyPicker`：当前家族置顶，多变种使用二级菜单，单变种直接提交。菜单匹配忽略可选 PostScript 元数据，提交仍携带完整字体身份。弹窗输入通过视觉祖先和逻辑祖先归属业务面板。

宿主从共享字体服务注入 `IFontNamePreviewProvider`。`Controls/Media/FontNamePreviewPresenter` 只请求可见名称并拥有位图；离开界面树时取消自身等待并拒绝过期结果。Rendering 打开真实字体 face 或可变字体命名实例，返回与主题无关的 Alpha8 蒙版。`DesktopApplicationContext` 拥有 `PreferencesStore.DirectoryPath/caches/fonts/v1` 中的有界缓存，缓存键包含字体内容及实例、名称、字号与 DPI；控件不访问磁盘或自行创建缓存。

## 窗口与输入

复用字体、间距、面板圆角和窗口外观；布局绘制外框，面板避免重复边框。为浮窗/设置宿主注册相同菜单与快捷键策略。

macOS 默认系统菜单，窗口菜单模式只在主工作台显示菜单。Windows 外观接入系统标题栏动作和缩放。主题/快捷键更新保留命令身份，语言重组在安全菜单生命周期进行。

## 效果库存储与分享

`EffectLibrary/` 将样式和脚本编辑器组合在一个非模态窗口中，可从欢迎页或**编辑 → 效果库**打开，无需工程。应用上下文拥有唯一共享的 `EffectLibraryRepository`；对字幕的应用仍由 Workspace 中现有流程负责。

托管的 `effect-library/` 目录包含版本化 manifest，以及每个样式／脚本的独立不可变文件。manifest 通过一次原子替换发布有序条目、字体族映射和修订号，未提交文件不会进入可见快照。原始字体在同级 `fonts/` 按内容寻址保存；整族更新与样式在同一次提交中生效。旧版单文件库会被忽略并保留原文；首次加载旧版目录库时，将整个目录原样备份到同级 `effect-library.legacy-<标识>/`，随后从空的新库开始，不显示旧库错误。旧版交换文件仍不能导入，当前格式的损坏清单仍会报错。文件由应用管理，不监听外部修改。

分享使用样式 ZIP `.aegistyles`、保留个人脚本库 Guid／名称／源码的 JSON `.aegieffect`，以及导出选中项或全部个人素材的 ZIP `.aegilibrary`。样式包自动携带本机可用的完整字体族；同一包中的字体按内容去重。导入确认后字体安装到用户配置目录的 `fonts/`，与 `caches/` 同级，仅供 AegiNext 使用。UTF-8 `.aegifx` 只保存源码及其中的 DSL 标识，内置脚本通过此格式导出。素材包不包含设置或仓库修订号；完整导出保留样式时间后处理关联与字体字节。

效果库各页的**导出…**入口打开同一个模态选择窗口，读取打开时已保存素材的固定快照。树初始没有勾选，只包含个人样式和脚本，编辑页的选择及未保存草稿保持独立。搜索匹配名称和脚本标识；树根复选框只操作可见匹配项，被隐藏的勾选按稳定身份保留。独立工具按钮全选或全不选整个快照，包括隐藏条目；搜索框内的清空操作只改变搜索词。默认使用打包格式；独立文件支持两种素材，原文格式要求非空且只选脚本。全库导出通过全选后以当前格式**导出所选素材**完成。脚本页的单独原文入口导出选中的已保存个人脚本及内置脚本原文。取消位置选择保留窗口状态，错误在窗口内显示并允许重试；关闭时取消待完成的文件选择／任务等待，等待导出清理后释放窗口。

覆盖到当前样式需要单选一个已保存的库样式，固定目标标识，用选中字幕的参数替换其外观，保留目标名称和时间处理器关联，不新增预设。系统／已安装应用字体只记录名称、变体及其他参数，不依赖重新枚举或采集系统字体；工程字体引用则保存原始字体族。导出统一收集完整字体族，缺失源文件时拒绝发布包。覆盖任务的本次异常传到效果库窗口，成功后保留目标选择；已有素材草稿先走保存／放弃／取消确认。

导入可混选多个独立文件和素材包。分析冻结已验证输入及当前仓库修订号；相同条目跳过，冲突按提供的导入／替换／跳过选项明确选择。交叉身份和内置条目受保护，同组输入版本最多选择一个。确认后原子合并两种素材并保留已有本地 Guid；预览过期必须重新分析、再次确认。导入不执行清空全库的恢复，分享文件／任务错误在本页显示。

特效脚本预览组合未保存原文、示例文字／时长和使用应用字体库的个人样式。View 拥有播放控制、视口和 Presenter 的生命周期，ViewModel 保留草稿与输入状态。专用工作线程创建、渲染并释放一个原生场景，使用 200 ms 防抖、单个待显示帧、代次检查和显示确认。隐藏时在最后显示的位置暂停；关闭时清空 Presenter 并等待工作线程释放。渲染复用字幕管线，不修改工程或 Undo；解析／渲染错误仅显示在预览区。工作台已有特效卡片保留原来的预览尺寸与行为。

## 用户设置备份与迁移

在设置导入导出页导出版本 3 的 `.aegisettings`。包中包含已提交偏好、压制预设、字幕颜色标记、当前布局与个人布局预设；不包含效果库素材、内置资源、最近工程、缓存或工程资产。分享整个个人效果库时，在效果库导出窗口全选，选择**效果库包（.aegilibrary）**，再点击**导出所选素材**。

导入先验证、预览设置，再安排下次启动恢复。手动导入仍可读取版本 1／2 的设置包，但忽略其中的样式和脚本。默认保留本机工程目录；音频校准只作用于完全匹配的设备链。可选颜色标记缺失时保留本地集合。待恢复操作可取消，或通过正常的未保存工程退出流程完成。

`Settings/Transfer/` 组合各层存储合同，不向 Application 或 Media 引入 Desktop 依赖。新恢复只在启动时以带日志的事务替换设置文件；应用阶段失败或中断会恢复原始字节，保留待恢复包供重试，已提交的事务日志则继续清理。包含旧版样式的待恢复包会被拒绝并保留原文；已经产生的旧事务日志仍沿用原有恢复规则。已存在托管效果库 manifest 时，旧恢复不能覆盖更新的素材。内置资源仍由程序提供。

## 本地化

外部 UTF-8 JSON 语言包位于 `I18n/Languages/`，复制到应用 `i18n/`。包含 `LanguageName`、`LanguageID` 和字符串值的 `Strings`，语言 ID 与键不能重复。

- C# 使用 `Localization.Get("Key")` 和 `Localization.SetLanguage(...)`。
- XAML 使用 `{Loc Key=...}` 实时绑定。
- 查找回退：当前语言 → `en-US` → key。
- 自动发现语言包，保留系统语言匹配和个人偏好。
- 字幕内容、预设名称与 DSL 语法保持业务数据。

不添加 Tag/树扫描。语言包修改后重启，发布时校验并记录哈希。可移植规范见[控件](../../.agents/skills/aeginext-controls/SKILL.md)和[本地化](../../.agents/skills/aeginext-localization/SKILL.md) Skill。

## 验证接入

运行受影响的 Desktop 控制器测试和 Desktop.Ui Headless 测试，使用真实 View、指针/按键输入及可控服务边界，并关闭所有测试宿主。原生菜单、拖拽/停靠、全屏、多屏、DPI 与 IME 外观需对应平台交互检查。
