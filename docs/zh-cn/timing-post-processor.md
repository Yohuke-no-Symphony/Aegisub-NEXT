# 时间后处理

[English](../en/timing-post-processor.md) · [简体中文](timing-post-processor.md) · [全部指南](README.md)

## 保存样式关联

1. 打开**设置 → 时间后处理**。
2. 选择样式行读取已保存选项，或编辑候选参数。
3. 勾选目标预设，点击**保存关联**，为这些预设统一保存配置。
4. **解除关联**移除勾选预设的配置。

样式来自个人库，无需打开工程或视频。该页面保存配置。

## 对选中片段执行

在时间线选中字幕片段，点击左侧按钮条最底部的时钟图标。处理器使用各字幕样式已保存的关联参数，按提前开始／延后结束、相邻接续、关键帧吸附的顺序执行；整批一次撤销。不同轨道分别处理，相邻接续只作用于同轨道、参数相同且直接相邻的选中字幕。未选字幕和纯图形片段保持不变。

没有关联参数的字幕会跳过，日志显示实际修改及跳过数量。没有视频时跳过关键帧阶段；探测失败、无效时长或最终碰撞拒绝整批。每次点击都执行一次，F8/F9、样式套用和导出不会自动运行处理器。

首次无缓存索引扫描会显示在标题栏任务列表中，可显式取消；扫描期间工程继续允许编辑。取消等待探测进程退出及资源回收。应用结果前重新校验工程、媒体、目标选择、字幕输入、草稿与手势版本；上下文已变化则放弃应用，避免覆盖新的编辑。索引缓存继续复用，取消请求不会立即移除任务行。

## 默认参数

| 步骤 | 默认值 |
|---|---|
| 提前开始 / 延后结束 | 开启，100 / 350 ms |
| 相邻字幕 | 开启，最大空隙 300 ms、最大重叠 50 ms、结束偏置 90% |
| 关键帧吸附 | 开启；开始前/后 200/150 ms，结束前/后 200/250 ms |

引擎按上述顺序处理，阈值包含边界；0% 偏置调整下一句开始，100% 调整上一句结束。执行关键帧吸附需要真实视频帧索引。

Enter 或失焦提交有效整数，无效草稿保持可编辑，Esc 恢复当前字段。点击**保存关联**前，候选参数与已保存关联独立。

## 存储与处理

关联使用稳定样式 ID：重命名保留、复制继承、删除移除，`.aegistyles` 随预设交换。样式元数据使用 v8；新版 `.aegistyles` 使用 ZIP 保存样式和完整字体族，不读取旧版样式文件。

工程在字幕片段中保存样式预设 ID。当前格式为 v14，可读取 v3–v14，兼容范围见[时间与存储](architecture.md#时间与存储)。旧字幕没有 ID 时，执行时优先解析名称一致的轨道预设，其次按个人库中精确相同的样式名兼容匹配。旧字幕仍叫 `Default`，但样式内容与开启自动应用的轨道默认样式完全一致，且个人库没有同名预设时，也使用该轨道的关联。成功处理时保存解析出的 ID。已有 ID 对应的预设失效时不会自动匹配同名新预设。

引擎使用有理时间并按轨道计算相邻关系；无效时长或最终碰撞拒绝整批结果，裁剪保持动画相位。帧索引读取真实 PTS，支持 VFR 和非零原点；时间错误或媒体/工具身份变化会拒绝索引。
