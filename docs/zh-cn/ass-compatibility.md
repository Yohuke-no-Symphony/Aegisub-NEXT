# ASS 互转换能力

[English](../en/ass-compatibility.md) · [简体中文](ass-compatibility.md) · [全部指南](README.md)

AegiNext 使用原生字幕、文字范围、卡拉 OK、动画和蒙版模型。ASS 是文件交换格式；导入将可对应的内容转为原生数据，导出生成目标格式并返回损失提示。工程保存不经过 ASS，因此文件交换的精度和能力限制不会改写原生工程。

逐标签的原生关系、双向转换能力和实现状态见 [ASS 标签核查](ass-tag-audit.md)。操作入口见 [字幕编辑](subtitle-editing.md#导入与导出)。

## 可对应的内容

| 内容 | 原生对应与边界 |
|---|---|
| 命名样式 | 导出共享的命名 Style，由 Dialogue 引用；基础属性继承样式表，正文只保留必要局部差量与效果。完整源样式表及原始覆盖来源不保真，见下节 |
| 文字、字体与强调 | 字体家族、字号、字距、粗体、斜体、下划线、删除线及局部覆盖；嵌入字体、命名变体和自定义行高不能完整保存在 ASS 中 |
| 颜色与透明度 | 填充、描边、阴影及卡拉 OK 激活前后的填充；ASS 为 8 位 sRGB，原生线性颜色、HDR 和独立通道可能产生量化或范围损失 |
| 排版与位置 | 九宫格对齐、三项边距、静态位置、非负二维缩放和 Z 旋转；字体度量、缩放与自动换行的先后顺序不同 |
| 旋转原点交换 | 显式定位或可测量的固定自动排版、固定正缩放下的整行旋转，以及静态旋转与单段匀速移动，可通过现有局部轴心和位置转换 `\org`；不增加原生画布定点旋转模式 |
| 卡拉 OK | `\k`、`\kf`/`\K`、`\ko` 和 `\kt`；完整组时间与范围外观分别保存，不自动拆为逐字计时 |
| 动画 | 可对应的数值、颜色、阴影偏移、直线移动和透明度包络；幂函数或有序操作直接转换，其他可求值的文字轨道按需采样 |
| 蒙版 | 矩形和受支持的矢量裁切；可对应的矩形动画输出 `\t`，其他原生蒙版动画展开为逐帧事件 |
| 静态图形 | 隔离、显式定位的简单闭合 ASS 绘图可导入原生路径；独立无孔洞轮廓拆为图形层。静态原生图形导出为绘图坐标，描边为有损近似；混排、自动绘图定位、裁切、阴影／模糊及动画不属于此导入范围 |

“参数可对应”不表示画面逐像素一致。文字塑形、栅格化、阴影轮廓、模糊与淡化合成仍由各自渲染器决定。阴影条件存在差异时会返回 `Ass.ShadowComposition`；模糊返回对应的外观和通道耦合提示。

## 命名样式与正文差量

导出在 `[V4+ Styles]` 中写出命名样式，Dialogue 的 Style 字段引用对应名称。同名且除边距外的 ASS 输出字段相同的字幕共用定义；工程中的不同名称即使字段相同也分别保留。同名但其他输出字段不同的定义会使用唯一后缀；名称中的逗号、首尾空白及冲突改名通过 `Ass.StyleName` 提示，不改写工程中的名称。

字体家族、字号、布尔强调、基础颜色、描边、对齐等可由样式表提供的属性直接继承，不在每条正文中完整展开。没有局部覆盖或额外效果时，正文可以只有文字。局部差异写为必要标签；后续样式、卡拉 OK 或动画范围边界仍以 `\r` 恢复当前 Dialogue 样式，再补局部差量、几何与必要动画，保留事件时钟。修改导出文件的 Style 属性会影响继承该属性的文字，输出文件中的显式局部覆盖继续独立生效。

比较依据是实际 ASS 编码，而不是原生浮点值：数字按最多 9 位小数，RGB 与 alpha 分别按 8 位输出值比较。量化后与基线相同的局部值按继承输出，不保留显式覆盖身份；实际精度、字体身份和外观语义损失仍会提示。`\blur`、必要的 `\q`、精确字重、独立或有符号阴影轴、定位、几何、卡拉 OK、动画和蒙版等仍按需写入正文。负字距及负阴影不能由样式表对应标量继承时，表中归零，正文保留必要的 `\fsp` 或 `\xshad/\yshad`。

共享样式的左、右、垂直边距分别处理。某轴在同组字幕中的输出编码全部相同时，共同值写入 Style，Dialogue 该轴写零继承；不同时，Style 该轴写零，各条 Dialogue 写自己的实际值。因此仅边距不同不会拆分样式，真实的零边距也不会误继承另一条字幕的非零值。判断按序列化结果进行，不先截断成整数来决定是否共用。蒙版展开出的同源事件沿用相同的样式引用和边距。

这些规则保留可对应的样式属性与共享关系，不恢复完整源文件结构。未被正文使用的 Style、原始 `\rStyle` 引用、属性来自 Style 还是正文的出处，以及原有 margin 的覆盖／继承写法不保存。未用于计时文字的 SecondaryColour 也不作为独立源样式字段保存；样式 Encoding 未还原，导出写固定值。缩放和旋转可转入原生几何，再输出等效标签，不保证仍位于原 Style 字段中。继续编辑并保留原生数据请保存 `.aeginext`。

## 交换时的限制

ASS 对白时间为厘秒，变换时间为整数毫秒；项目内部保留精确时间。导出对白起点向下、终点向上取整，卡拉 OK 起止独立量化，折叠的正时长至少保留一厘秒。数值最多输出 9 位小数；数值、颜色和 alpha 实际发生舍入时分别提示。

外部文件的三项有效边距取事件最终重置样式的值，包括正文之后的 `\rStyle`；Dialogue 中每项非零边距分别覆盖样式，零值继承。样式重置仍保留事件对齐和显式定位。

原生独立填充、描边和阴影模糊不能完整映射到 ASS 的单一 `\blur`。非等比描边或模糊重采样使用近似，并报告损失。缺少有效 `LayoutRes` 时按现有分辨率信息估算。

连续卡拉 OK 描边／阴影动画采用有损文字导出：每个范围的共用通道按未激活、已激活、普通顺序选择一条动画，保留文字和计时，两种高亮状态共用该轨道。模糊合并到单一 blur，按事件起点选择边缘；落选轨道、对应激活瞬变和状态身份丢失并提示。原生工程和高级编辑投影保留独立数据。

原生镜像、独立高亮边缘动画、重叠范围几何、复杂运动路径、整层模糊、图片和图形合成可能被近似或省略。导出只影响输出文件；省略项及原因进入损失提示。

独立文字范围平移，包括逐组弹跳的 POSITION 轨道及静态范围 Offset，没有直接的 ASS 文字标签对应，完整事件或字形烘焙适配仍未完成。导出报告 `Ass.RangeTranslation` 并省略该移动，不会将它改为整句位移。反向非线性曲线按属性使用文字动画采样、数值／移动／透明度近似或蒙版事件展开；原生工程曲线仍保留精确时序。

ASS 的 3D 旋转、剪切、独立横纵描边、重复盒式边缘模糊、字符编码覆盖和行内绘图没有完整的当前适配。具体是原生模型缺失、格式不可表达还是适配器未完成，在标签核查中分别列出。

## 旋转轴心的文件适配

原生工具继续编辑局部轴心、位置和动画。文件导入在显式 `\pos`、可转换的 `\move` 或可测量的固定自动排版、固定正缩放、整行一致的几何条件下，将 `\org` 换算为现有像素轴心与位置。桌面与 CLI 通过共享渲染器提供最终固定排版测量，保留原点坐标，但不保证 libass 自动排版的逐像素外观。固定位置允许整行旋转动画；移动与旋转动画同时存在时不进行此换算。事件内首个有效原点生效，不随 `\r` 重置，尾部或 `\t` 内的原点也作为固定事件属性处理；`\t` 标签列表前的说明文字不妨碍提取原点。

固定几何按事件半开可见窗口 `[Start, End)` 判断。窗口前已完成、窗口后才开始或在起点立即完成的变换，只有源操作与导入轨道都能证明窗内恒定且数值一致时，才进入轴心换算；成功转换的相关有序轨道规范为常量，便于再次导出。窗内仍有变化、源几何需要采样，或几何变换已被舍弃时，不以首尾值或剩余轨道推断可精确转换。

导出将支持的原生几何转换为固定 `\org` 与等效定位、移动和旋转标签。原点不从裁切后的移动首值推导，蒙版展开的各个事件共用同一原点。符合上述条件且未经编辑的导入数据，在工程保存、读取后可以恢复有效原点与运动语义；其他原生轴心生成几何等效的 ASS 表达，不承诺原生字段结构往返一致。原标签的存在、顺序、重复次数和写法不保存。

缺少固定排版测量的自动定位原点、动态缩放、有效范围位移／缩放／旋转、零缩放轴，以及非等比画布重采样与旋转的组合，不属于当前精确适配范围。仅颜色、分组来源信息或有效缩放为 1、旋转为 0 的范围不会阻止适配；导出这些范围时保留整行几何与动画。导入与导出自动定位或自定义排版轴心需要完整的固定排版测量；一次静态测量不能补偿变化的字号和字距。超出条件或派生坐标越界时，只舍弃原点适配并保留其他可转换内容，不扩展原生变换模型或采样原点补偿。

已识别的数值、时间和排版损失分别报告。`\move` 的两个整数毫秒时间均不大于零时，导入按完整对白时长解释；仅起点为负的移动保留裁切后的真实运动阶段。

## 高级 ASS 编辑与文件导入

高级 ASS 编辑页是原生数据的临时文本投影。未改写的时间、颜色精度、字体资源、独立外观和可保留的原生轨道会恢复原值；普通正文或局部样式修改不会自动把工程降为 ASS 精度。改写了某个标签时，只有对应的可表示属性进入解析与更新。

文件导出的样式精简不用于此编辑页；高级编辑仍使用完整样式投影，保留现有的属性编辑与原生数据恢复规则。

范围 Offset、生成块来源及父范围引用、局部 POSITION 轨道，以及不可表达的反向文字曲线在投影中保留；采样出的 ASS 标签不会取代被保留的原生反向曲线。修改文字后需要重新分组或重排特效时间时，应按[特效脚本](effect-dsl.md)说明重新应用模板。

文件导入使用外部 ASS 语义，包含源操作顺序、空参数重置、卡拉 OK 时钟和分辨率换算。高级编辑投影与外部文件的能力边界不同，不能把投影文本当作完整工程备份；保留原生能力应保存 `.aeginext`。

`\org` 的坐标适配只用于文件交换；高级 ASS 编辑页仍通过原生轴心属性管理几何，不接收外部 `\org` 定位语义。

## 诊断与预算

转换结果包含可定位到字幕、来源标签或属性的诊断。无法对应的标签、轨道或部分非法数值与变换时间只舍弃受影响的部分；非法文件结构、对白起止时间、UTF-8 或硬资源预算则拒绝整个操作。取消导入或导出不会提交转换结果。

| 诊断类别 | 含义 |
|---|---|
| `Ass.StyleName` | 输出样式名称因分隔符、首尾空白或同名定义冲突而调整；工程名称不变 |
| `Ass.UnsupportedTag`、`Ass.Drawing` | 来源内容没有当前原生适配 |
| `Ass.TransformLayout`、`Ass.TextRangeGeometry` | 参数保留，但排版与变换顺序可能改变外观 |
| `Ass.RangeTranslation` | 输出省略独立文字范围平移 |
| `Ass.RotationOrigin` | 原点参数或几何组合不满足当前适配条件；其他可转换内容保留 |
| `Ass.KaraokeVisual`、`Ass.KaraokeAnimation` | 高亮状态的独立边缘或轨道无法完整表达 |
| `Ass.NumberPrecision`、`Ass.ColorPrecision`、`Ass.AlphaPrecision` | 输出值发生数值或 8 位量化 |
| `Ass.TimeQuantization`、`Ass.TransformTimeQuantization`、`Ass.KaraokeQuantization` | 输出时间发生量化 |
| `Ass.AnimationSampling`、`Ass.AnimationSamplingLimit` | 插值转为采样结果；达到限制时部分区间可能超过采样误差目标 |
| `Ass.MaskAnimationExpanded`、`Ass.MaskQuantization`、`Ass.MaskTimeQuantization` | 蒙版事件展开、坐标或时间量化 |
| `Ass.MixedMaskAnimation` | 导入静态矢量与矩形动画的组合时省略矩形动画，完整混合动画适配未完成 |
| `Ass.Image`、`Ass.AnimatedImage`、`Ass.ShapeAnimation`、`Ass.ShapeBlend`、`Ass.ShapeBlur`、`Ass.ShapeOpenStroke` | 输出省略对应图片或不受支持的图形片段；受支持的静态图形仍可导出 |
| `Subtitle.Composition` | 字幕图层存在未转换的轨道、运动路径或非普通混合模式 |

文字动画采样限制为每轨道 4096 点、1 毫秒时间网格，导出最多 100,000 条事件，均属于交换预算。每字幕最多 256 个动画文字范围同时是原生工程校验约束。

实现集中在 [SubtitleFormats](../../src/AegiNext.SubtitleFormats/)；原生能力由 [Core/Projects](../../src/AegiNext.Core/Projects/) 定义，画面由 [Rendering](../../src/AegiNext.Rendering/) 求值与合成。
