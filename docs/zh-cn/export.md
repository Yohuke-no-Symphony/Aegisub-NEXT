# 视频导出

[English](../en/export.md) · [简体中文](export.md) · [全部指南](README.md)

## 导出视频

1. 打开**压制**面板，选择自动、H.264、HEVC、VP8、VP9 或 AV1。
2. 选择 CPU 或 GPU 编码及速度。CPU 的质量模式随格式显示为 CRF 或 CQ，也可选择 Mbps 下的 VBR/CBR；GPU 使用 VBR/CBR。
3. 选择复制源音频、AAC、Opus 或无音频；AAC/Opus 可设置音频码率。
4. 点击**导出**，选择所选格式支持的容器和一个尚不存在的目标文件。
5. 查看进度，必要时取消，完成后检查输出。

自动格式对 SDR 选择 H.264，对 PQ/HLG 选择 HEVC。已保存工程的默认位置为 `项目目录/output/项目名-yyyyMMdd-HHmmss.扩展名`，首次压制时自动创建 `output` 目录；自动、H.264、HEVC 默认 MP4，VP8、VP9、AV1 默认 MKV。保存对话框允许修改位置、文件名及兼容容器；未保存工程须选择输出位置。

导出在开始时捕获工程，通过独立 `aegn-exporter` 进程执行；后续编辑不影响任务。成功时原子提交新文件，失败/取消只清理自己的临时输出；已有目标文件会被拒绝。参数校验、输出路径选择、任务启动或编码失败时显示错误原因，并将完整详情记录到日志。确认错误后可以修正参数重试；取消压制不显示错误弹窗。

## 选择编码格式与质量

| 格式 | CPU 编码器 | 质量模式、范围与默认值 | 输出与容器 |
|---|---|---|---|
| H.264 | libx264 | CRF 0–51，默认 20 | SDR 8-bit；MP4、MKV |
| HEVC / H.265 | libx265 | CRF 0–51，默认 20 | 10-bit；MP4、MKV |
| VP8 | libvpx | CQ 0–63，默认 32 | SDR 8-bit；MKV、WebM |
| VP9 | libvpx-vp9 | CRF 0–63，默认 32 | 8/10-bit；MKV、WebM、MP4 |
| AV1 | libsvtav1 | CRF 1–63，默认 32 | 8/10-bit；MKV、WebM、MP4 |

CRF/CQ 数值越低，画质和体积通常越高；不同格式的数值不能直接比较。VP9 的 CRF 0 启用无损编码；AV1 的最小值为 1，不能套用其他格式的 0。VP9/AV1 对高于 8-bit 的源或 HDR 使用 10-bit，否则使用 8-bit；压制输出采用 4:2:0。

VP8 的 CQ 是受目标码率约束的质量模式，需要同时设置质量和 Mbps。其他格式的 CRF 不使用目标码率。所有格式均可使用 VBR/CBR，视频目标码率为 **0.1–200 Mbps**，默认 **8 Mbps**，按 1 kbps 精度向下规范化。VBR 允许码率随内容变化；CBR 使用恒定目标及缓冲约束。实际文件平均码率受内容、片长和编码器影响，短片或单帧的实测值不保证等于输入值。

速度有 ultrafast、superfast、veryfast、faster、fast、medium、slow、slower、veryslow 九档，默认 medium。更慢的档位通常花费更多时间来改善压缩效率；各编码器采用各自的速度参数，同名档位不代表相同速度或画质。GPU 将这些档位映射到后端提供的速度级别。

## 选择 CPU 或 GPU

CPU 可在 macOS 和 Windows 使用上述全部格式。GPU 只加速视频编码，字幕合成仍使用线性高精度链路；视频解码策略由媒体设置另行决定。

| 格式 | macOS GPU | Windows GPU 候选 |
|---|---|---|
| H.264、HEVC | VideoToolbox | NVENC、QSV、AMF |
| VP8 | 无 | 无 |
| VP9 | 无 | QSV |
| AV1 | 无 | NVENC、QSV、AMF |

候选存在还需要对应 GPU、驱动、位深和码控支持。硬件模式保持 VBR/CBR，不自动切换 CPU 或其他码控；全部候选失败时报告后端原因。VP8 没有 GPU 选项；macOS 的 VP9/AV1 请使用 CPU。RTX 3090 Ti 可以进行 H.264/HEVC 编码，不能硬件编码 VP8、VP9 或 AV1；支持 AV1 解码不表示支持 AV1 编码。AV1 编码能力见 [NVIDIA 官方支持矩阵](https://developer.nvidia.com/video-encode-decode-support-matrix)。

QSV 的完成信息确认配置已被接受并完成编码器初始化；当前锁定运行时不能提供独立的运行时码控查询证据。GPU 候选与软件测试通过不代表某张实体显卡已验收，实际输出、驱动和 HDR 保真需要在目标设备确认。

## 选择容器与音频

MKV 是 VP8/VP9/AV1 的默认容器，方便保存原音轨；需要 WebM 时在保存对话框选择 `.webm`。VP8 不支持 MP4，H.264/HEVC 不支持 WebM。VP9/AV1 的 MP4 是否能播放还取决于目标播放器的解码能力。

复制源音频保留压缩音频包；AAC/Opus 重新编码选定音轨，码率范围为 **32–512 kbps**，默认 **192 kbps**。无音频生成静音成片，源中没有音轨时也不会凭空添加音频。

WebM 音轨只支持 Opus 或 Vorbis：复制这两种源音轨可用，AAC 或其他格式的原样复制会在编码视频前被拒绝。应用不静默改用 Opus；请明确选择 Opus、无音频，或改用 MKV。其他容器的原音轨复制也会先尝试封装兼容性检查。时间戳无法保留时提供诊断，不静默移动源时间线。

最终封装还会核验首尾采样裁剪和章节。原样复制跨容器导致采样变化，或 MP4 无法保留源章节时间时，导出会失败；保留原音轨和章节可优先选择 MKV。

## 管理压制预设

在**设置 → 压制预设**新增或复制预设，编辑名称及编码参数后保存。选择已有预设并保存会修改该预设；**捕获当前配置**将当前工作台压制参数复制为新的独立草稿。切换选择、页面或关闭设置时，未保存的修改可以保存、恢复或取消切换。

列表支持多选；**导出**将选中的已保存预设写入一个 `.aegiexports` 文件。**导入**支持同时选择多个交换文件，每个文件也可包含多条预设。新文件使用版本 2，版本 1 的旧预设会迁移并保留原有参数；旧应用不能读取新格式。文件版本、参数、身份或名称冲突会拒绝整批导入，不部分入库。交换文件不包含工程、媒体路径、成片路径或工具路径。

回到**压制**面板，直接选择预设即可套用。个人库修改和导入只刷新可选列表，当前参数与未完成输入保持原样，直到主动选择预设；管理预设不会提交工程草稿或改变 Undo。

## HDR 与输入要求

编辑预览为 SDR；PQ/HLG 导出读取原始高精度帧，使用 HEVC、VP9 或 AV1 的 10-bit 输出。H.264/VP8 HDR 会被拒绝。macOS VideoToolbox HDR 编码不在当前导出合同内，请使用 CPU；Windows 硬件 HDR 还取决于后端支持和成片元数据核验。

- PQ 字幕参考白默认 203 nits；HLG 使用 1000 nits、零黑位参考条件。
- 保留完整静态 HDR10 mastering 与输入携带的 MaxCLL/MaxFALL；这些字段不代表应用重新测量了合成后成片的亮度。
- 完成前核验编码视频及最终容器的实际编码、位深、色彩与静态 HDR 元数据；不符时拒绝提交成片。
- Dolby Vision/HDR10+ 等动态 HDR、变化/不完整 mastering 和不支持的色彩语义会被拒绝。
- 输入须为受支持的整数平面 YUV、方形像素，画布为偶数尺寸并与可见视频尺寸一致；VFR 保留源呈现时间戳。
- 旋转、立体、ICC、交错、损坏/动态格式，以及封装链路不支持的负时间戳会报告错误。

ASS/SRT 文件见[字幕编辑](subtitle-editing.md)，应用包要求与校验见[发布](publishing.md)。
