# ASS tag audit

[English](ass-tag-audit.md) · [简体中文](../zh-cn/ass-tag-audit.md) · [All guides](README.md)

This table uses AegiNext's native editable capabilities as the benchmark against the [Aegisub ASS tag catalog](https://aegisub.org/docs/latest/ass_tags/). AegiNext does not aim to reproduce Aegisub's data model or renderer. See [ASS interoperability](ass-compatibility.md) for file-exchange boundaries.

## Classification

| Dimension | Meaning |
|---|---|
| Native relationship | **Superset**: a broader value domain, independent channels, or editing freedom; **Subset**: only part of the capability; **Not implemented**: no corresponding native semantics; **Same implementation**: the shared capability defined by this row corresponds |
| Conversion capability | **Lossless**: parameters, geometry, or timing survive under this row's conditions; **Lossy**: quantization, approximation, sampling, lost independent information, or differing composition; **Cannot convert**: no corresponding representation in the current model or target format |
| Implementation status | **Complete**: the described conversion and necessary loss handling exist; **Incomplete**: an existing model can carry it, but the adapter is unfinished; **Cannot complete**: direct tag correspondence needs a new native capability or a different output form |

Capability and implementation are separate: a lossless but incomplete adapter is not available yet. A lossy but complete adapter has the explicitly bounded fallback implemented and still loses information; complex conversion with only diagnostics and omission remains incomplete. Cannot complete is limited to the current model, rather than a permanent claim about future extensions.

Lossless does not include original tag spelling or order, operation identity, source-file metadata, or pixel equivalence. Shared parameters must satisfy native validation and output precision: at most nine decimal places, centisecond dialogue/karaoke time, integer millisecond transforms, and 8-bit color/alpha. Actual quantization makes a conversion lossy and produces diagnostics. Different capabilities of a tag occupy separate rows; no single row covers all its uses.

Per-operation numeric constraints, style normalization, default arguments, and permissive parsing are checked against libass 0.17.5 reference semantics. Permissive inputs and reference extensions are listed separately; they are not claims about the ASS standard or every player. The blur cap of 100 belongs to this reference implementation.

## Placement, transforms, and animation

The current `\t` animated-property whitelist is fs, fsp, bord, blur, fscx/fscy, fr/frz, shad/xshad/yshad, c/1c–4c, alpha/1a–4a, and rectangular clip/iclip. In external files, org inside t remains a fixed event origin, fsc immediately resets both axes, and vector clip/iclip remains static clipping; these do not animate the corresponding properties. Other nested properties produce unsupported-tag diagnostics. The unfinished equal-axis xbord/ybord animation adapter is listed separately.

| Tag or capability scope | Native relationship | ASS→native | Native→ASS | Import / export status | Boundary |
|---|---|---|---|---|---|
| Static `\pos` placement | Same implementation | Lossless | Lossless | Complete / Complete | Exporting custom pivots requires real font measurement; missing measurement uses a lossy placement estimate |
| Single constant-speed straight `\move` with ordered, positive duration | Same implementation | Lossless | Lossless | Complete / Complete | Source times use integer milliseconds; four arguments or two zero times use event duration. Reversed and instantaneous cases are listed separately |
| `\move` both-nonpositive full-duration fallback | Same implementation | Lossless | Lossless | Complete / Complete | When both times are nonpositive after integer-millisecond parsing, the complete dialogue duration is used; discarded fractional milliseconds retain their diagnostic |
| `\move` reversed-time swapping | Same implementation | Lossless | Lossless | Complete / Complete | External files swap reversed time endpoints, then apply the both-nonpositive fallback. Source movement coordinates and representable timing survive; equal positive-time jumps remain separate |
| Instantaneous `\move` with equal positive times | Same implementation | Lossy | Lossy | Incomplete / Incomplete | Native HOLD and ordered jumps exist, but the source still uses the first point at the boundary and the last afterward, requiring millisecond boundary adaptation. Import skips it; export rejects these tracks and falls back to static placement |

File fields have separate limits: nonempty Effect fields and BorderStyle 3 background boxes are not imported; font/image attachments are not loaded; original comments, script metadata, and tag spelling do not fully round-trip. Native literal `\\` followed by control characters such as N/n/h can be rejected when safe output is impossible. Literal braces use libass extension escaping with a cross-player diagnostic. These limits preclude lossless source-file preservation.
